# Latent Factor Financial Analysis

This repository contains the materials from a project conducted as a part of **STAT 355: Multivariate Analysis** in the Department of Statistics at **Williams College**.

This project applies classical multivariate techniques, principal component
analysis (PCA), hierarchical clustering, exploratory and confirmatory factor analysis (EFA/CFA), and multivariate inference (MANOVA, Hotelling’s T^2), for uncovering latent structure in firm-level financial statements.
